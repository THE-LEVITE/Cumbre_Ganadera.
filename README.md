# CumbreGanadera

## Descripción Breve
Nuestro sistema se centrara en la gestion de haciendas con todos sus aspectos primordiales, ademas de la venta de productos de cada hacienda

## Tecnologías utilizadas
- ASP.NET Web Forms
- SQL Server
- Bootstrap

## Funcionalidades principales
- Login
- Registro de usuarios
- Asignacion de tareas
- Venta de productos
- Gestion y monitoreo de Animales
- Administracion de inventario
- Control de solicitudes

## Instrucciones de uso
Primero se deberá clonar el proyecto a través de la url https://github.com/THE-LEVITE/Cumbre--Ganadera.git desde alguna interfaz de Visual Studio, siguiente a esto se debe dirigir a la solución del proyecto dando click derecho sobre esta y ejecutando las 3 principales opciones.

1. Restaurar Paquetes NuGet
2. Limpiar Solución
3. Recompilar Solución

Estas opciones se deben ejecutar en este mismo orden, siguiente a esto se debe ejecutar el aspx llamado RegistroCliente que se encontrara en Vista/Auth/RegistroCliente.aspx continuando así con el inicio de sesión y el respectivo uso de la web.
